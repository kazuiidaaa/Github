# 在留資格案件管理（visa-case-app）

行政書士向けの案件管理アプリです。個人情報を扱うため、運用前に必ず次を確認してください。

- 環境変数と本番化の手順：[docs/production.md](docs/production.md)
- Supabase の設定手順：[supabase/README.md](supabase/README.md)

## 開発

```bash
cp .env.example .env.local   # 開発用 Supabase の値を入力（未設定でも仮データで動作）
npm install
npm run dev
npm run lint && npm test
```

実案件のデータは、開発環境へ入力しないでください。

## デモの共有

ログインせずに操作を試せる「デモを試す」ボタンは、ログイン画面（`/login`）にあります。デモ用のリンクを共有する場合は、トップページではなく、次の URL を案内してください。

```
https://<公開先のドメイン>/login
```

- 案内する手順：上記の URL を開き、「デモを試す」を押す。
- デモ中の入力内容は、サーバーに保存されません。画面右上の「デモを終了」を押すと消去されます。
- Supabase の接続情報が未設定の環境（仮データ方式）では、ログイン画面にボタンは表示されません。その環境では、ログインせず、そのまま操作できます。
- 実案件のデータは、デモに入力しないでください。
