# 作業の要点（詳細は docs/working-rules.md）
- 着手前に、対象の Issue と、前任の5項目のコメントのみを読む。
- 作業終了時、Issue に5項目の短いコメントを書く（各1〜3行）。
- 個人情報を、Issue・PR・docs・コード・ログに書かない。
- 1つの目的につき1つの PR。下書きで作成し、`Closes #番号` を書く。
- PR 本文の1行目に、競合の有無を書く（GitHub 上の状態で確認）。
- Issue を、独自の判断で起票しない。課題は、作業中の Issue に提案として書く。
- 1セッションの担当は、1〜2件まで。
- 統合用ブランチ（用1・用2）の運用は、docs/working-rules.md に従う。
