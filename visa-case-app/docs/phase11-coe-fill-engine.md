# フェーズ11：在留資格認定証明書交付申請書の差し込みエンジン（Issue #86）

方式は `docs/phase11-renewal-fill-engine.md`（#79。座標はロック解除セルの機械的列挙で特定、テストの書き方、exceljs の制限）、画面・履歴への統合は `docs/phase11-official-form-ui.md`（#80）。本書は、**認定固有の判断と、Issue 本文・原本・既存の項目表との食い違い**を記録する。項目の根拠は `docs/phase13-coe-forms-research.md`（#85）。

> **追記（フェーズ15）**：本書の「入国目的（11）・同伴者(15)・出入国歴(17)・認定申請歴(18)・犯罪処分(19)・退去強制歴(20)・在日親族の有無(21)の○・チェックは対象外」という記述は、利用者の明示の指示により方針転換し、差し込み対応済み（入国目的は、案件の希望する在留資格が様式の選択肢と一字一句一致する場合に限る）。詳細は `docs/phase15-checkbox-pick-fill-engine.md` を参照。

## 設計判断

* **書くのは「入力欄のうち、案件DBに対応する値があるもの」だけ**（更新と同じ）。値は文字列で書く（日付の年・月・日、金額も数値にしない）。
* **有無の詳細は「有」のときだけ書く**（17・18・20）。更新で、犯罪処分(19)の具体的内容と在日親族を「有」のときだけ書くのと同じ。有無が未選択（空）のときは、回数や年月日を入力していても書かない。有無そのもの（有・無の○）は対象外。
* **性別・配偶者の有無は選択式（`PickItem`）**。更新と同じく、選ばれなかった側と「・」の文字を空にする。認定は、性別が `E23`・`G23`・`H23`、配偶者が `AK23`・`AM23`・`AN23`（更新は配偶者が結合セル1つ `Y21`）。配偶者は「有」「無」の文字がそれぞれ別セルのため、更新と書き換え方が異なる。同伴者(15)・出入国歴(17)・認定申請歴(18)・犯罪処分(19)・退去強制歴(20)・在日親族の有無(21)・同居予定の有無（`V95` など「有・無」）の○は、Issue の方針どおり対象外。
* **対象範囲の判定（`COE_SPEC.isInScope`）は手続種別のみ**。認定は海外からの呼び寄せで、現に有する在留資格がない。判定に使える入国目的（`targetStatus`）は、`OfficialFormScope` に含まれていない。含めると画面・履歴の共通コードに触れるため（#84・#88 と衝突する）、本Issueでは行わない。このため、入国目的が様式（Nシート＝技術・人文知識・国際業務、高度専門職1号イ・ロ、研究、介護、技能、特定活動の一部が対象）の対象外でも、注意は出ない。行政書士が、様式選択表（`申請人用（認定）１（裏)`）で確認する。
* **業種・職種は番号のときだけ書く**（更新と同じ。主たる業種 `AG27`・主たる職種 `AF65`）。他の業種・他の職種（`AF30`・`AE68`）は案件DBに対応する値がないため空欄。
* **warnings**：申請人情報が未確定、在日親族が5人以上、職歴が7件以上、活動内容詳細が3行以上、業種・職種が番号でない、法人番号・雇用保険適用事業所番号の桁数不一致（所属機関用1・2）。

## テストについて

`coe.test.ts` は、#79 と同じ5種類（座標の整合、差し込み結果、無入力、レイアウト保持、warnings）に加え、有無が「有」でないときに詳細を書かないこと、性別・配偶者の選択式を確認する。値はすべてダミー。テンプレートの空欄の一部（`Z95`・`J78` など）には空白1文字が入っているため、値の比較は前後の空白を無視する。

## 既知の制限・目視確認

* exceljs で失われるものは #79 と同じ。認定では、`申請人用（認定）` の**写真枠（図形のグループ「Group 1」、`drawing1.xml`）**と、プリンター設定の埋め込みデータ（`printerSettings*.bin`）が出力に含まれない。A4（`paperSize=9`）・倍率・向き・シート保護・結合セル・印刷範囲は保たれる（テストで確認）。
* Excel／LibreOffice での目視確認は、本Issueの作業環境でも実施できていない。LibreOffice（`soffice`）はあるが、テンプレートそのものも出力ファイルも「source file could not be loaded」となる（#79 と同じ）。マージ前に、行政書士または担当者が、出力ファイルを Excel／LibreOffice で開いて確認すること。
