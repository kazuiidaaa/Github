# 案件一覧の「変更後／希望の在留資格」表示（#82）

## 決定事項
- 対象：`procedureType` が `change`（在留資格変更）または `coe`（認定証明書交付）の案件。判定は `lib/types.ts` の `needsTargetStatus()`。新規案件画面の `needsTarget`（`app/cases/new/page.tsx`）と同じ条件。
- 表示内容の組み立ては、純関数 `getTargetStatusDisplay()`（`lib/types.ts`）に切り出し、`tests/targetStatus.test.ts` で検証する。画面（`app/cases/page.tsx`）は、その結果を表示するだけにする。
- ラベルは手続種別で出し分ける（新規案件画面の入力欄と同じ考え方。認定は海外からの呼び寄せで、現在の在留資格がないため）。

| 手続種別 | 表（md 以上） | カード（md 未満） |
| --- | --- | --- |
| `change` | 変更後：○○ | 変更後の在留資格 |
| `coe` | 希望：○○ | 希望する在留資格 |
| `renewal`・`other` | 表示しない（従来どおり） | 表示しない（従来どおり） |

- 表（md 以上）：列は追加せず、既存の「在留資格」セルの2行目に表示する。横幅を増やさないため。
- カード（md 未満）：`dl` に項目を1行追加する。
- 未入力：氏名欄と同じく、灰色の「未入力」を表示する。空・空白のみ（全角空白を含む）の値も「未入力」とする。値の前後の空白は取り除いて表示する。

## 備考
- `app/cases/new/page.tsx` 側の判定は、範囲外のため変更していない（`needsTargetStatus()` への置き換えは別途可能）。
