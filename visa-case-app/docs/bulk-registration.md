# まとめて登録の案件名（Issue #44）

## 方針
- 「複数人をまとめて登録」では、案件名を「グループ名」から生成する。グループ名は必須（100文字以内）。
- 申請人（案件名）の行入力は任意とする。
  - 入力のある行：その入力を案件名とする（従来どおり）。
  - 空欄の行：`グループ名（行番号）` を案件名とする。行番号は、空欄かどうかに関わらず、画面上の並び順（1始まり）。
- 空欄の行も案件として作成する（従来は空欄の行を無視していた）。作成件数は行数と一致する。
- 入力したグループ名は、グループ（`case_groups`。設計は `docs/case-groups.md`）の名前として残し、作成する案件をそのグループに入れる（主たる申請人との関係は空欄。各案件の詳細で設定する）。グループの機能が使えない間（移行 0027 の未適用）は、従来どおり案件名の生成にだけ使い、保持しない。案件名は作成後、通常の案件名と同じ扱いで、「案件情報」から個別に変更できる。
- 「1件ずつ登録」は変更しない。

## 理由
まとめて登録の時点では、申請人の氏名が未確定なことが多い。所属機関・手続種別・人数の単位で案件群を把握する実務に合わせた。

## 実装
- 生成処理：`lib/bulkCaseNames.ts`（テスト：`tests/bulkCaseNames.test.ts`）
- 画面：`app/cases/new/page.tsx`
