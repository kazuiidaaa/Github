# 入力フォームの自動保存（Issue #45）

## 目的
申請人情報・雇用・会社情報・公式様式項目の各タブで、保存ボタンを押す前にタブを切り替えても入力内容が失われないようにする。

## 方針
- `lib/useAutoSaveForm.ts` を追加した。`lib/useAutoSave.ts`（1つの文字列項目用、Issue #28）と同じ考え方（入力停止後1秒で保存、画面が取り除かれる際に未保存なら保存）を、フォーム全体の値に適用する。既存の `useAutoSave` は変更していない。
- 保存関数が `false` を返した場合（検証エラー）は保存せず、未保存のまま残す。内容が変わるたびに再度試す。
- 手動の保存ボタンを押したときは `markSaved` で保存済みの内容を記録し、同じ内容を重ねて保存しない。

## フォームごとの扱い
| フォーム | 自動保存の内容 | 保存しない条件 |
|---|---|---|
| 申請人情報 | 既存の `saveDraft` と同じ（`validateDraft`、下書きとして保存） | 確認済みの間（入力欄が無効）、`validateDraft` にエラーがある場合 |
| 雇用・会社情報 | 既存の `save` と同じ | `hasEmploymentDateError` がある場合 |
| 公式様式項目 | 既存の `save` と同じ | `validateFormDetails` にエラーがある場合 |

- 「確認済みにする」は、自動では行わない。
- 自動保存でも、既存の「保存しました。」「下書きを保存しました。」の表示と、監査ログ（`*_saved`）を使う。
- 検証エラーのある内容は、自動保存されない。タブを切り替えるとその入力は失われる（従来どおり、エラー解消後に保存する）。

## 留意点
- 自動保存でも監査ログが記録される。値は記録しない（既存の仕様のまま）。
- DOM テスト用のライブラリ（jsdom、testing-library）が未導入のため、フックの自動テストは追加していない。動作は画面で確認する。
