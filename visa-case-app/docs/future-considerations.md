# 今後あらためて検討する設計課題

作成日：2026-10-03 / 状態：**保留**（今回はIssue化を見送り、設計をあらためて検討する）

## 1. 所属機関（雇用先）情報の、複数案件にまたがる共有化

背景：Issue「同一所属機関の複数の申請人をまとめて新規登録できるようにする」の検討にあたり、同一の会社に所属する複数の申請人の案件であっても、雇用・会社情報（`employment_details` テーブル、`components/EmploymentForm.tsx`）が案件ごとに独立して保持されている構成であることを確認した。

今回の対応：新規案件の作成時に、入力した雇用・会社情報を複製して、複数案件をまとめて作成する簡易な対応にとどめる。作成後の案件間で情報を同期する仕組みは導入しない（各案件は、作成直後から独立したレコードとして扱う）。

今後の検討課題：所属機関を、案件から独立した共有エンティティとして管理し、1か所の変更を関連する全案件に反映できるようにするかどうか。実現する場合は、次の点の検討が必要になる。

- データモデル：`organizations`（本アプリを利用する事務所を表す既存テーブル）とは別に、「顧客の所属機関」を表すテーブルを新設するか、`employment_details` の持ち方自体を見直すか
- 既存データの移行方法（案件ごとに保持している雇用・会社情報を、共有エンティティへどう統合するか）
- 1つの所属機関情報を、複数の案件・複数の行政書士が参照する際の、権限・編集競合の扱い
- 必要書類の判定（`lib/requirements/evaluate.ts`）など、雇用・会社情報を参照している既存ロジックへの影響範囲

要確認：上記の設計変更に見合う利用規模（同一所属機関の案件数）になった時点で、あらためて検討する。

## 2. 高度専門職の優遇措置のうち、永住許可の要件緩和への対応

作成日：2026-10-05 / 状態：**保留**（Issue化は見送り）

背景：高度外国人材は、永住許可の在留歴の要件が緩和される（出入国在留管理庁の公開ページ）。通常は引き続き10年以上の在留が必要だが、高度外国人材としての活動を引き続き3年間行っている場合、またはポイントが80点以上で、その活動を引き続き1年間行っている場合は、永住許可の対象となる。

今後の検討課題：案件のポイント（`lib/hspPoints.ts`）を使い、80点の基準と、高度外国人材としての活動の継続期間を、画面に示すかどうか。現在、画面と警告は、70点の基準のみを扱う。

要確認：永住許可の申請の手続（必要書類、様式）は、現在、本アプリの対象外。対象にする場合は、手続の追加から検討する。

## 3. 業務の記録（帳簿）の管理

作成日：2026-10-06 / 状態：**保留**（今回は見送り）

背景：行政書士法には、業務に関する帳簿の備付けの定めがある（受任の年月日、報酬の額などを記載する）。本アプリには、該当する項目が見当たらない。受任日は、Issue #225 で、案件の項目として追加する。

今後の検討課題：帳簿としての記載事項・保存期間を、法令の原典で確認したうえで、案件の情報から出力できるようにするかどうか。

要確認：記載事項と保存期間は、条文（行政書士法、同施行規則）を確認してから決める。

## 4. アプリ全体の表示言語の切替（利用者ごとの言語設定）

作成日：2026-10-06 / 状態：**保留**（Issue #251 では、ご案内書類のみ対応）

背景：Issue #251 で、依頼者向けのご案内書類（`client_guide`）だけ、日本語・英語・韓国語で表示・出力できるようにした（docs/client-guide-languages.md）。画面全体（ボタン、メニュー、案内文）は、日本語のみ。

今後の検討課題：利用者ごとの言語設定として、アプリ全体の表示言語を切り替えるかどうか。言語の型（`lib/documents/lang.ts` の `Lang`）と訳表は、広げやすい置き場所・命名にしてある。実現する場合は、次の点の検討が必要になる。

- 言語設定の保存先（利用者ごと。今回の案内書の言語は、ブラウザの localStorage のみ）
- 訳表の置き場所（今回は、ご案内書類専用の `lib/documents/clientGuideText.ts`）と、訳文の確認の運用
- 書類名の訳（`lib/documents/clientGuideNames.ts`）の追加・確認の運用
- 出力した Word・PDF の言語を、版の記録に残すか（今回は残さない。ファイルの中身だけに反映する）

要確認：利用規模と、利用者の言語の分布を確認してから決める。
