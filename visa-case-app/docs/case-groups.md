# 案件のグループ（フォルダ）（Issue #474、関連 #456）

家族の同時申請など、人ごとに独立した案件を、一つのまとまり（グループ）で管理する。

## 決定事項（利用者承認済み）
- グループの表 `case_groups`（名前・組織・作成日）。案件 `cases` に、グループ欄 `group_id`（任意。1案件は1グループのみ）と、「主たる申請人との関係」欄 `group_relation`（任意）を足す。
- 関係の選択肢は 3 つ：主たる申請人（`primary`）／帯同者（`companion`）／その他（`other`）。空欄可。画面の見出しは「主たる申請人との関係」（「続柄」という語は使わない）。
- 主たる申請人は、1グループに何人置いてもよい（人数制限なし。全員が主たる申請人でも、全員が空欄でもよい）。
- 関係は**表示用の印のみ**。判定・自動処理（期限の連動、必要書類の補助、在留資格の整合確認）は作らない。手続・書類・期限は、人ごとの案件で独立のまま。
- 空になったグループは削除せず残す。グループを削除しても案件は消えない（`on delete set null (group_id)`）。
- 見える範囲・編集権限は既存の案件と同じ（組織単位。RLS は `cases` と同等。viewer は閲覧のみ）。
- 既存の案件は、案件詳細から後で「グループに入れる／移す／外す」ができる。新しいグループをその場で作って入れることもできる。
- 一覧はグループごとにまとめ、グループ外の案件は従来どおり。グループ内は主たる申請人を先頭、同じ関係なら登録順。関係は色だけでなく文字でも示す。
- 「まとめて登録」で入力したグループ名を、グループの名前として残す。

## 移行 0027 が未適用の本番でも従来どおり動く仕組み
- 読み込み：`loadAll` は `select("*")` のため、列が無くてもエラーにならない（`group_id` は未設定として扱う）。グループの表は `loadGroups` が別に取得し、表が無いエラー（`42P01`・`PGRST205` など）のときだけ、空・無効として扱う。権限や通信のエラーは握りつぶさず、他の読み込みと同様に失敗として扱う。
- 保存：`persistCase` は、`loadGroups` で表を確認できたときだけ `group_id` / `group_relation` を送る。未適用のときは送らないため、従来どおり保存できる（0023 の受任日と違い、列の有無に依存しない）。
- 画面：`useGroupsAvailable()` が false の間は、グループの操作を出さない。`createGroup` は無効の間は何もしない（null を返す）。
- 仮データ・デモ：保存先 `visa-case-app:groups:v1`（デモは別の名前空間）。デモの開始時に架空のグループを 1 つ用意し、終了時に消す。

## PR-2（PC 版）で変わる画面
- 案件一覧（`components/CaseListTable.tsx`、`app/cases/page.tsx`）：グループに入っている案件を、グループごとにまとめて表示する。グループの見出し行（フォルダの印・名前・件数）の下に、案件を少し字下げして並べる。グループは、その最初の案件が一覧に現れる位置に置くため、並び順の指定（最終更新・期限・案件名）はグループ外の案件とそろう。グループ内は、主たる申請人を先頭、同じ関係なら登録順（`lib/caseGroups.ts` の `orderRowsByGroup`）。ページ分割もこの並びで行い、グループがページをまたぐときは、次のページの先頭にも見出しを出す。幅が足りないときのカード表示にも、同じ見出しと印を出す。グループ外の案件は従来どおり。
- 関係の印（`components/GroupRelationBadge.tsx`）：「主たる申請人」（青）、「帯同者」「その他」（灰）。文字で示し、色だけに頼らない。
- 案件詳細の概要（`components/CaseGroupSection.tsx`）：案件情報の下に「グループ」の欄。グループ名、主たる申請人との関係、同じグループの他の案件へのリンクを示す。編集できる役割には「変更」ボタン：グループなし／既存のグループ／新しいグループを作る、と、関係（指定なし／主たる申請人／帯同者／その他）を選ぶ。外しても案件は消えない。閲覧のみの役割は、表示だけ。
- まとめて登録（`app/cases/new/page.tsx`）：グループ名をグループの名前として残し、作る案件をそのグループに入れる（関係は空欄）。
- 空のグループは、一覧には出さない（案件詳細のグループ選択には出る）。
- 保存の記録：グループ・関係の変更は、監査ログに「案件情報の保存（変更された項目名 groupId のみ）」として残す。値は残さない。
- 文言は `caseGroup` 区分（日・英・韓。英・韓は下書き）。
