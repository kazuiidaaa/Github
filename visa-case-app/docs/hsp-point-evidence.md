# 高度専門職ポイント計算表の疎明資料（Issue #186）

出典：ポイント計算表（出入国在留管理庁、`docs/official/hsp-point-calculation-sheet_930001673.xls`）の「疎明資料（基本例）」シート。
案内ページ：https://www.moj.go.jp/isa/applications/status/designatedactivities02_00004.html
A＝高度専門職第1号イ、B＝同ロ、C＝同ハ。1号の各シートは、第2号と共用する。

## 必要書類の規則（`lib/requirements/rules.ts`）
- 規則集合：`HSP_COE`（認定）・`HSP_CHANGE`（変更・1号）・`HSP_CHANGE_2`（変更・2号）・`HSP_RENEWAL`（更新・1号）。
- 載せている書類は、ポイント計算表（`hsp_point_table`）と、疎明資料（`hsp_point_evidence`）の2件のみ。**他の提出書類の規則は未整備**のため、規則集合の名称に「ポイント計算表・疎明資料のみ整備」と表示する。
- 取得許可申請は対象外。取得の規則集合は、取得の事由で判定する（在留資格を問わない）ため、高度専門職の規則を足さない。また、取得の「希望する在留資格」に高度専門職は選べない。
- 高度専門職2号は在留期限が無期限のため、更新の規則はない。2号は、案件の変更後の在留資格「高度専門職（2号）」（`lib/types.ts` の `ADVANCED_PROFESSIONAL_GRADE_2`）で選ぶ。選べるのは、手続種別が変更のときのみ。
- 照合は部分一致のため、「高度専門職（1号イ）」等の保存値は、`高度専門職` の規則に一致する。2号は、1号より先に照合する（`RULE_SETS` の並び順）。他の在留資格の規則とは、一致しない（`tests/evaluate.test.ts`）。
- 疎明資料は、**1件の必要書類**として管理する（収集状況：未受領・依頼済み・受領済み・確認済み）。計算表のどの項目を主張するかは、ポイント入力（未実装）がないと決まらないため、項目ごとの要否は判定しない。

## 未実装（Issue #186 の残り）
- 計算表の入力項目（学歴・職歴年数・年収・年齢・研究実績・各種加算）と、案件情報での持ち方
- 公式様式（`.xls`）への差し込みと、合計点の算出（70点・年収300万円未満の注意）
- 取り込んだ `.xls` は、実行時に読める `.xlsx` ではない。Excel 等で `.xlsx` として保存し直して `docs/official/` へ追加すれば、既存の方式（`PickItem`）で差し込める

## 高度専門職2号の変更：所得・納税・社会保険の書類（Issue #188）
`HSP_CHANGE_2`（`lib/requirements/rules.ts`）に、ポイント計算表・疎明資料のほか、次の書類を載せている。日本で発行される証明書は、発行日から3か月以内のもの。

| 書類 | 判定 | 対象期間・注記 |
|---|---|---|
| 住民税の課税（非課税）証明書・納税証明書（各1通） | 必要 | 直近5年分。70点以上を維持して3年以上継続在留：直近3年分。80点以上を維持して1年以上継続在留：直近1年分 |
| 住民税の納付を証明する資料（通帳の写し、領収証書等） | 要確認 | 直近3年間すべて特別徴収の場合は不要 |
| 住民税の資料の提出が困難な理由書 | 要確認 | 納付を証明する資料を提出できない場合のみ |
| 国税の納税証明書（その3）5税目 | 必要 | 直近5年分 |
| 所得を証明するもの（預貯金通帳の写しなど） | 必要 | 直近5年分 |
| 公的年金の保険料の納付状況を証明する資料 | 必要 | 直近2年間。80点以上を維持して1年以上継続在留：直近1年分 |
| 公的医療保険の保険料の納付状況を証明する資料 | 必要 | 同上 |
| 事業所の保険料に関する資料 | 要確認 | 申請時に、社会保険適用事業所の事業主である場合のみ |
| 80点以上を確認できる資料 | 要確認 | 80点以上として、提出資料の一部の省略を希望する場合のみ |

- 点数・在留期間・申請人の状況（特別徴収、年金・医療保険の制度、事業主かどうか）による分岐は、案件の入力項目にしていない。ポイント入力（#186 の残り）がないと点数が決まらず、他の分岐は、推測できないため、書類ごとの注記と「要確認」で案内し、行政書士が判断する。入力項目にするかは、#186 の入力設計と合わせて、別途決める。
- 高度専門職（1号）の変更・認定・更新には、これらの書類を出さない。
