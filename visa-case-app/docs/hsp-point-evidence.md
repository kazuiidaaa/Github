# 高度専門職ポイント計算表の疎明資料（Issue #186）

出典：ポイント計算表（出入国在留管理庁、`docs/official/hsp-point-calculation-sheet_930001673.xls`）の「疎明資料（基本例）」シート。
案内ページ：https://www.moj.go.jp/isa/applications/status/designatedactivities02_00004.html
A＝高度専門職第1号イ、B＝同ロ、C＝同ハ。1号の各シートは、第2号と共用する。

## 必要書類の規則（`lib/requirements/rules.ts`）
- 規則集合：`HSP_COE`（認定）・`HSP_CHANGE`（変更・1号）・`HSP_CHANGE_2`（変更・2号）・`HSP_RENEWAL`（更新・1号）。
- 載せている書類は、ポイント計算表（`hsp_point_table`）と、疎明資料（`hsp_point_evidence`）の2件のみ。**他の提出書類の規則は未整備**のため、規則集合の名称に「ポイント計算表・疎明資料のみ整備」と表示する。
- 取得許可申請は対象外。取得の規則集合は、取得の事由で判定する（在留資格を問わない）ため、高度専門職の規則を足さない。また、取得の「希望する在留資格」に高度専門職は選べない。
- 高度専門職2号は在留期限が無期限のため、更新の規則はない。2号は、案件の変更後の在留資格「高度専門職（2号）」（`lib/types.ts` の `ADVANCED_PROFESSIONAL_GRADE_2`）で選ぶ。選べるのは、手続種別が変更のときのみ。
- 照合は部分一致のため、「高度専門職（1号イ）」等の保存値は、`高度専門職` の規則に一致する。2号は、1号より先に照合する（`RULE_SETS` の並び順）。他の在留資格の規則とは、一致しない（`tests/evaluate.test.ts`）。
- 疎明資料は、親の**1件の必要書類**として管理し、計算表の項目を選ぶと、番号ごとの書類が加わる（下の「疎明資料の番号ごとの管理」）。どの項目を主張するかの最終判断は、行政書士が行う。

## ポイント計算表の入力と差し込み（Issue #186）
- 差し込み元：`docs/official/points-calculation-table_930001673.xlsx`（`.xls` を Excel で保存し直したもの。`.xls` は参照用）。
- チェック欄の定義：`lib/hspPointRows.ts`（A＝1号イ、B＝1号ロ、C＝1号ハ。各シートの AF 列のロック解除セル□を、項目名・印字点数・疎明資料の番号とともに持つ）。`lib/documents/excelFill/hspPoint.test.ts` が、全行が実在の□を指すこと、定義に漏れがないことを照合する。様式が改正されたら、再生成して照合する。
- 保存：`FormDetails.hspPointSheet`（2号・号が未選択のときに、使うシートを選ぶ）と `hspPointChecks`（「シート:行」の一覧。例：「B:20」）。DB の変更はない（JSON）。
- 画面：案件の「申請書の補足情報」に、高度専門職の案件のとき「高度専門職のポイント計算表」を表示する（`components/HspPointSection.tsx`）。号から使うシートが決まり、2号・号が未選択のときは、シートを選ぶ。認定・変更は希望する在留資格、更新は現在の在留資格で判定する。
- 差し込み：選んだチェック欄を ■ にして、使うシートだけを出力する（`fillHspPointExcel`。API は `official-form` に `form: "hspPoint"` を付けて呼ぶ）。**点数・合計欄は書き込まない**。
- 目安の合計点：選んだ項目の印字点数の単純合計と、70点の基準を画面と警告に表示する。研究実績の2つ以上の組み合わせ、特別加算の上限、年齢による年収の範囲は、判定しない（行政書士が計算表で確認）。択一の区分（職歴・年収・年齢・地位）を複数選ぶと注意し、年収が未選択のときは、年収300万円未満の注意を出す。
- 差し込まない欄：「資格」（1つ・複数）、投資運用業等（A・B）、特別加算の試験研究費等の割合、申出人の署名・作成年月日。判断が必要な加算（大学一覧・日本語能力など）は、推測せず、行政書士の選択とする。

## 疎明資料の番号ごとの管理（Issue #186）
- 選んだチェック欄から、疎明資料の番号（①〜㉑）を導き、**番号ごとに1件の必要書類**として、収集状況（未受領・依頼済み・受領済み・確認済み）・期限・メモを持つ（`evidenceNumbers`、`lib/hspPoints.ts`）。必要書類の一覧では、親の「ポイント計算表の疎明資料」の直後に並ぶ。保存は、既存の必要書類と同じ（`requirementStates`。規則の id は `hsp_point_evidence_①` のように番号を付ける）。DB の変更はない。
- 番号ごとの書類は、**「要確認」**（`check`）で出す。疎明資料は、ポイントの合計が70点以上あることを確認できれば足り、該当する全項目の資料は不要なため、一律に必要とはしない。提出するものを、行政書士が「判断」で「必要」に切り替える（切り替えると、必要書類の件数と未受領の件数に数える）。
- 番号の導き方：各行は、様式のAL列（結合セルの範囲を含む）の番号を持つ。**「直前の行と共通」とは読まない**（日本語能力は⑮、指定の大学は⑰で、直前の⑭・⑯とは異なる）。この対応は、`hspPoint.test.ts` が様式と照合する。年齢の行には、番号の記載がない。1つの行に2つの番号がある場合（中小企業者の研究費：⑩⑫）は、両方を出す。
- 出さない場合：使うシートが決まらない間（2号・号が未選択でシートを選んでいない）、項目を選んでいない間は、親の疎明資料1件のみ。
- 導けない番号：チェック欄を持たない項目（資格＝⑧、投資運用業等＝㉑のうちシートA・B）は、番号が導かれない。必要なときは、案件の「規則にない書類」に追加する。

## 高度専門職2号の変更：所得・納税・社会保険の書類（Issue #188）
`HSP_CHANGE_2`（`lib/requirements/rules.ts`）に、ポイント計算表・疎明資料のほか、次の書類を載せている。日本で発行される証明書は、発行日から3か月以内のもの。

| 書類 | 判定 | 対象期間・注記 |
|---|---|---|
| 住民税の課税（非課税）証明書・納税証明書（各1通） | 必要 | 直近5年分。70点以上を維持して3年以上継続在留：直近3年分。80点以上を維持して1年以上継続在留：直近1年分 |
| 住民税の納付を証明する資料（通帳の写し、領収証書等） | 要確認 | 直近3年間すべて特別徴収の場合は不要 |
| 住民税の資料の提出が困難な理由書 | 要確認 | 納付を証明する資料を提出できない場合のみ |
| 国税の納税証明書（その3）5税目 | 必要 | 直近5年分 |
| 所得を証明するもの（預貯金通帳の写しなど） | 必要 | 直近5年分 |
| 公的年金の保険料の納付状況を証明する資料 | 必要 | 直近2年間。80点以上を維持して1年以上継続在留：直近1年分 |
| 公的医療保険の保険料の納付状況を証明する資料 | 必要 | 同上 |
| 事業所の保険料に関する資料 | 要確認 | 申請時に、社会保険適用事業所の事業主である場合のみ |
| 80点以上を確認できる資料 | 要確認 | 80点以上として、提出資料の一部の省略を希望する場合のみ |

- 点数・在留期間・申請人の状況（特別徴収、年金・医療保険の制度、事業主かどうか）による分岐は、案件の入力項目にしていない。ポイント入力は、印字点数の単純合計（目安）のみで、正式な点数が決まらず、他の分岐は、推測できないため、書類ごとの注記と「要確認」で案内し、行政書士が判断する。入力項目にするかは、#186 の入力設計と合わせて、別途決める。
- 高度専門職（1号）の変更・認定・更新には、これらの書類を出さない。
