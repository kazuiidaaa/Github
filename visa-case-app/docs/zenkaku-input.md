# 半角の文字を全角へ自動変換する入力欄（Issue #223）

## 目的
住所・会社名などの日本語の入力欄に、半角のカナ・英数字・記号・空白が混ざったまま保存されると、公式様式への差し込みや書類の表記が不揃いになる。そこで、入力の確定時に全角へそろえる。

## 変換の時点
- IME の確定時（`compositionend`）と、欄を離れたとき（`blur`）のみ。入力途中・IME の変換中は書き換えない。
- `compositionend` は、ブラウザーにより確定後の入力イベントの前に届くことがあるため、1 回待ってから欄の値を読む。
- 既存の保存済みデータは、一括では変換しない。表示時にも変換しない。画面で編集して欄を離れたときのみ、変換後の値になる。
- 郵便番号から補った住所（#226）は、入れる時点で変換する。`components/AddressField.tsx` は、住所の欄に既定で変換を付ける（呼び出し側の変更は不要）。

## 変換の規則（`lib/zenkaku.ts`）
- 種類は 3 つ。
  - `full`：半角のカナ・英数字・記号・空白を、すべて全角にする。
  - `kana`：半角のカナのみ全角にする（氏名・国籍、国外の住所・地名〔本国における居住地・出生地・査証申請予定地〕など、ローマ字で書かれることがある欄）。ローマ字・英数字・ハイフンは、そのまま。日本の住所（full）のみ、ハイフンを全角「－」にそろえる。
  - `none`：変換しない（既定）。
- 半角カナは、濁点・半濁点を結合して全角にする（ｶﾞ → ガ、ﾊﾟ → パ）。
- 半角の空白は、全角の空白（U+3000）にする。改行・タブは、そのまま。
- ハイフンは、全角のハイフン「－」（U+FF0D）にそろえる。長音「ー」・全角のダッシュ「―」は、変えない。
  - 根拠：公式の記載例（`docs/official/renewal-application-sample_001460062.pdf`）の住居地・電話番号が、U+FF0D の「－」で書かれている。
- 変換する欄の一覧は、`lib/zenkaku.ts` の表（`APPLICANT_ZENKAKU`・`EMPLOYMENT_ZENKAKU`・`FORM_DETAILS_ZENKAKU` など）。表に無い欄は変換しない。新しい入力欄を足すときは、番号・電話・日付・数量でなければ、表へ足すかを判断する。

## 変換しない欄
番号（在留カード・旅券・法人番号・雇用保険・職業コード）、電話、メールアドレス、日付、郵便番号、ローマ字の氏名（`Applicant.legalName`）、数量・期間（資本金・従業員数・月額給与・契約期間・在留期間・回数など）、パスワード。

## 差し込みとの関係
`lib/documents/excelFill/` は変更していない。画面で変換された値が、そのまま様式のセルへ入る（試験：`tests/zenkaku.test.ts`）。
